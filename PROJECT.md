# pdf-ocr-detector-by-jair-lima

## Descrição
Encontra PDFs sem camada de texto (só imagens escaneadas) e os abre em lotes para você aplicar OCR.

## Stack
Python 3, pypdf.

## Estrutura
Ver a lista de arquivos na raiz e o README.md.

## Comando essencial
`python ocr_detector.py --pasta "D:\Biblioteca"`

## Estado atual
Versão pública inicial (2026-10-17), extraída do projeto original do autor.

## Problemas conhecidos
Testado apenas no Windows.
